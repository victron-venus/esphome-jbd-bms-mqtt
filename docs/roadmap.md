# Roadmap through October 2027

esphome-jbd-bms-mqtt will prioritize compatibility, documented interfaces, failure handling and reproducible validation over expanding its supported deployment surface.

- October–December 2026: close evidenced security and correctness findings, maintain dependency updates and document supported configurations and upgrade impact.
- January–April 2027: add regression coverage around rejected inputs, interrupted operations and recovery; review the current release and contributor experience.
- May–October 2027: requalify supported toolchains and environments, reduce measured coverage gaps and review maintenance responsibilities.

A designated backup maintainer and an exercised access-recovery arrangement remain open governance work. No recovery owner or deadline has been promised. Proposals and priorities can be discussed in [issues](https://github.com/victron-venus/esphome-jbd-bms-mqtt/issues).

## Non-goals

This roadmap does not promise physical-device certification, unattended production deployment, complete dependency correctness, or support for every operating system and device. CI and synthetic tests do not replace operator acceptance on the intended target.
